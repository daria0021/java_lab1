# Лабораторная работа №1
**Выполнила:** Поликарпова Дарья, 25КНТ-1

Класс для работы с матрицами комплексных чисел на Java

---

## Возможности

- Сложение, вычитание, умножение матриц
- Деление матриц (через обратную матрицу)
- Транспонирование
- Вычисление определителя
- Консольный интерфейс для работы с матрицами

---

## О работе

Работа состоит из четырёх классов в пакете matrix.app. ComplexNumber хранит действительную и мнимую части числа и поддерживает базовую арифметику.
ComplexMatrix построена на двумерном массиве комплексных чисел и реализует операции над квадратными матрицами.
MatrixApp - точка входа с консольным меню для ввода данных и выбора операции.
Отдельно написан класс ComplexMatrixTest с юнит-тестами, которые проверяют корректность всех методов и обработку ошибок.

---

## Запуск

Собрать проект:

`mvn clean install`

Запустить тесты:
